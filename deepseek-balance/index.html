如何获取 Token？（30 秒）
  1. 在浏览器中登录 platform.deepseek.com
  2. 按 F12 打开开发者工具,切换到 Console（控制台）
  3. 粘贴以下命令并回车,Token 会自动复制到剪贴板：
    copy(JSON.parse(localStorage.userToken).value)
    若 copy 不可用,请执行 JSON.parse(localStorage.userToken).value 后手动复制输出的字符串
  4. 回到本页面,粘贴到上方输入框
Token 用于读取平台用量数据,会过期;若提示失效,重新获取即可。数据来自平台内部接口,仅供参考。
提示：用量数据来自平台内部接口,支持两种获取方式：
① 本地代理自动查询——先运行 启动服务器.bat（代理地址 —）,粘贴平台 Token 后点“查询用量”;
② 控制台导入（万能方案）——不用任何服务器,任何浏览器都能用,见下方“没有本地服务器？”。
没有本地服务器？用“控制台获取数据”导入（万能方案）
  1. 在浏览器中登录 platform.deepseek.com（保持登录状态）
  2. 按 F12 打开 Console（控制台）,粘贴「获取数据命令」并回车——数据会自动复制到剪贴板
  3. 回到本页面,点击 「从剪贴板导入并显示」,即可看到柱状图与明细
数据只在本机浏览器里处理,不会上传到任何服务器;每次想刷新数据时,重新执行一遍「获取数据命令」即可。
